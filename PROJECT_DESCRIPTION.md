# Portfolio description

Built a Python-based market strategy research prototype using pandas, NumPy, and yfinance. Implemented EMA trend filters, RSI/ATR pullback rules, historical strategy comparisons, a volatility-based exposure heuristic, and Discord webhook alerts. Investigated the tradeoff between drawdown reduction and participation in market gains, and documented backtesting and execution limitations.
